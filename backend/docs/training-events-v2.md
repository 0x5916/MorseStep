# MorseStep V2 Training Events API Specification

## 1. Overview & Idempotency Model

The V2 training event API provides offline-first, idempotent batch synchronization for immutable `AttemptEvent` records generated by MorseStep web and mobile clients.

### Key Guarantees
- **Strict Idempotency:** The composite key `(user_id, event_id)` is unique in storage. Re-uploading an already-persisted event ID returns an acknowledgment without duplicate ingestion or error.
- **Batched Ingestion:** Clients flush queued attempts in batches of up to 100 events per request.
- **Partial Acceptance:** A malformed individual event does not poison valid sibling events unless a critical payload violation occurs.
- **Clock Independence:** Client timestamps (`created_at`) record measurement timing, while server timestamps record ingestion time.
- **Legacy Preservation:** The existing endpoint `PUT /v1/cw/progress` remains active throughout the migration.

## 2. Endpoints

### 2.1 POST /v2/training/events/batch

Uploads a batch of prompt attempt events.

**Authentication:** Bearer token (JWT in `Authorization` header).

**Request Body:**
```json
{
  "schema_version": 1,
  "client_id": "client_uuid_v4",
  "client_sent_at": "2026-10-04T12:00:05.000Z",
  "events": [
    {
      "id": "att_rs_bm9ad04m",
      "session_id": "sess_rs_bm9ad04a",
      "prompt_id": "prm_rs_bm9ad04b",
      "prompt_kind": "recall",
      "target_character": "T",
      "entered_text": "T",
      "is_correct": true,
      "classification": "automatic",
      "latency_ms": 1200,
      "replay_count": 0,
      "input_mode": "keyboard",
      "char_wpm": 20,
      "eff_wpm": 12,
      "freq_hz": 600,
      "created_at": "2026-10-04T12:00:00.000Z"
    }
  ]
}
```

**Limits:**
- Max events per batch: 100
- Max payload size: 256 KB

**Response (HTTP 200 OK):**
```json
{
  "acknowledged_ids": [
    "att_rs_bm9ad04m"
  ],
  "rejected_events": []
}
```

**Partial Failure Example (HTTP 200 OK):**
```json
{
  "acknowledged_ids": [
    "att_rs_bm9ad04m"
  ],
  "rejected_events": [
    {
      "id": "att_bad_1",
      "error_code": "INVALID_TIMING",
      "message": "latency_ms cannot be negative"
    }
  ]
}
```

### 2.2 GET /v2/training/snapshot

Retrieves the user's aggregated learning snapshot across devices.

**Authentication:** Bearer token.

**Response (HTTP 200 OK):**
```json
{
  "suggested_step": 7,
  "unlocked_step": 7,
  "last_active_at": "2026-10-04T12:00:00.000Z",
  "character_masteries": [
    {
      "character": "K",
      "status": "stable",
      "rolling_accuracy": 0.94,
      "median_latency_ms": 1250,
      "total_attempts": 42
    }
  ]
}
```

---

### 2.3 PUT /v2/training/settings

Updates cloud-synchronized CW and learning preferences.

**Authentication:** Bearer token.

**Request Body:**
```json
{
  "char_wpm": 20,
  "eff_wpm": 12,
  "freq": 600,
  "start_delay": 0.5,
  "target_daily_minutes": 5
}
```

**Response (HTTP 200 OK):**
```json
{
  "updated_at": "2026-10-04T12:01:00.000Z"
}
```
