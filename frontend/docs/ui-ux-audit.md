# Frontend UI/UX backlog

Reviewed against the current source on 6 October 2026. Findings below are source-confirmed implementation gaps or explicit acceptance requirements; browser reproduction and remediation verification remain required. This is a frontend design/correctness backlog, not a security audit.

## Implemented baseline

The Learn dashboard now has one page-padding owner, localized heading/path/status/disclosure/practice copy, nearby course rows with expandable earlier/later lessons, and a width-constrained recommendation skeleton. New-device guidance uses the existing 60-day attempt query, not lifetime history. Recommendation/session/practice/progress localization is still incomplete.

Home now introduces guided recognition with a curriculum-derived first-lesson preview, device-local progress reassurance, and a secondary Practice action in all five locales. The centered hero has local telegraph-key, antenna, and radio-station illustrations at its edges; the lesson preview and method follow below. Phones use a smaller key illustration. Generation prompts are recorded in [home-artwork-prompts.json](home-artwork-prompts.json).

Progress and progression share batch mastery indexing; Learn preserves incremental reduction and its early exit. These changes do not implement saved-session restoration, sound comparison, or guided server sync.
